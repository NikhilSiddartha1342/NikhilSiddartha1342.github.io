## 🌐 Local Development & Setup

This portfolio is built with lightweight, zero-dependency static web standards (HTML5, modern CSS3, vanilla JavaScript ES6+), guaranteeing fast load times and clean cross-browser rendering.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NikhilSiddartha1342/NikhilSiddartha1342.github.io.git
   cd NikhilSiddartha1342.github.io
   ```

2. **Launch locally:**
   You can open `index.html` directly in your favorite browser, or run a local static server:
   ```bash
   # Using Python
   python -m http.server 8000

   # Or using Node.js
   npx serve .
   ```

3. **Visit in browser:**
   ```
   http://localhost:8000
   ```
